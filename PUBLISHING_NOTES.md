# Publishing notes

This repository is the clean public snapshot of CMM (Candidate Marketing
Machine) built for the Meta Global AI Developer Hackathon, Oct 26 – Nov 4, 2026.

Excluded from this public snapshot on purpose:

- The live demo store database (`attested.db` files) — binary working state,
  regenerated by running the flow; the text outputs (profiles, dossiers,
  tailored resumes, call queue) are included under `examples_out/`.
- The live event log of the owner's own website test session, which names
  the owner's real job applications.
- One website test upload that contained a real person's resume (filed
  under a demo persona's folder during testing). All personas in this
  repository (Alex Rivera, Jordan Lee) are fictional.

No API keys are in this repository. The Meta Model API key is read from
the `META_MODEL_API_KEY` environment variable (see `attested/meta_client.py`).
